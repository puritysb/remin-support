음성 메모

주요 기능

4단계 스마트 클러스터링

시간 → GPS → 시각 유사도 → 품질. 4가지 기준으로 베스트 컷을 자동 선별합니다.

지도 위 여정

이동 경로와 함께 그곳에서의 추억을 지도 위에 펼쳐봅니다.

동영상 생성

여행 사진으로 시네마틱 영상을 자동 생성합니다.

과거의 오늘

캘린더로 날짜별 사진을 탐색하고, 1년 전 같은 날을 되돌아봅니다.

🔒 모든 분석이 기기 내에서 이루어집니다. 사진이 외부로 전송되지 않습니다.

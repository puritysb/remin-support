개인정보처리방침

최종 업데이트: 2026-07-30

요약

  • Remin은 사진/동영상 분석을 위해 기기의 "사진" 접근 권한을 요청합니다.
  • 클러스터링, 품질 평가, 검색 색인, AI 여행 스토리까지 모든 분석은 기기 안에서 수행됩니다. 사진과 동영상은 저희에게 전송되지 않습니다.
  • Remin은 광고/트래킹 SDK를 포함하지 않으며, 제3자에게 데이터를 판매하지 않습니다.
  • 외부로 요청을 보내는 기능은 단 하나이며, 그것도 사용자가 직접 입력한 주소로만 갑니다. 네트워크 사용에서 설명합니다.

접근하는 정보

Remin은 앱 기능 제공을 위해 기기에서 다음에 접근할 수 있습니다.

  • 사진/동영상 및 메타데이터(촬영 시각, 포함된 경우 위치): 여행 사진 큐레이션, 검색, 콘텐츠 생성
  • 현재 위치: Apple Watch에서 순간이나 장소를 담을 때 기록하며, 장소 바로가기가 적용되는 지점을 보여주는 데 사용합니다
  • 마이크 오디오: Apple Watch에서 음성 메모를 녹음하는 동안에만

저장

Remin은 앱 동작을 위해 분석 결과, 설정, 음성 메모 녹음과 사용자가 적은 메모를 기기 내(로컬 데이터베이스·캐시)에 저장합니다.

기기 내 처리

  • 사진 클러스터링, 품질 평가, 시각 유사도, 검색 색인은 Apple의 Vision·Core ML 프레임워크로 기기에서 계산합니다.
  • 여행 스토리, 세션 이름, 시맨틱 태그는 지원 기기에서 Apple Intelligence의 기기 내 파운데이션 모델이 생성합니다. 프롬프트나 사진이 서버로 가지 않습니다.
  • 음성 메모는 녹음해 기기에 보관합니다. Remin은 음성을 글로 변환하지 않으며, 메모 옆에 보이는 글은 사용자가 직접 적은 것입니다.

네트워크 사용

Remin에는 자체 서버가 없습니다. 사진, 동영상, 위치, 음성 메모, 분석 결과는 어디로도 전송되지 않습니다.

장소 바로가기(선택). 장소에 웹 페이지나 이미지 주소를 등록하면, iPhone이 그 주소를 HTTPS로 받아와 담긴 코드를 읽어 Apple Watch가 도착할 때 보여줄 수 있게 합니다. 요청은 사용자가 입력한 호스트로만 갑니다. 모든 웹 요청과 마찬가지로 그 사이트 운영자는 접속 IP와 요청 시각을 볼 수 있으며, 사진·위치·분석 결과에 관한 정보는 어떤 것도 포함되지 않습니다. Apple Watch 자체는 네트워크를 사용하지 않습니다 — 완성된 코드를 iPhone이 넘겨줍니다. 주소를 등록하지 않으면 Remin은 외부로 어떤 요청도 보내지 않습니다.

이와 별개로, iCloud 사진 보관함을 사용하는 경우 사진이 기기로 내려받아지는 과정은 iOS 시스템(Apple 서비스)이 관리하는 네트워크를 사용할 수 있습니다.

추적

Remin은 사용자를 추적하지 않습니다. 분석 SDK, 광고 식별자, 저희에게 보고되는 크래시 리포터가 모두 없습니다.

권한

  • 사진 접근: 사진 선택·분석·앨범 생성
  • 위치(사용 중): 순간과 장소를 담은 위치 기록, 현재 위치에 맞는 장소 바로가기 표시
  • 마이크: Apple Watch 음성 메모 녹음

사진 접근을 제외한 모든 권한은 선택이며, 허용하지 않아도 나머지 기능은 그대로 동작합니다.

데이터 삭제

앱을 삭제하면 음성 메모 녹음과 사용자가 적은 메모를 포함한 Remin의 로컬 데이터가 함께 제거됩니다. (원본 사진과 앨범은 사용자가 Photos 앱에서 관리합니다.)

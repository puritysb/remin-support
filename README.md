## About Remin

Remin은 여행 사진을 자동으로 정리하고, 아름다운 영상으로 만들어주는 iOS 앱입니다.

### Features

- **Smart Clustering**: 시간, GPS, 시각적 유사도, 품질 기반 4단계 자동 분류
- **Journey on Map**: 여행 경로를 지도 위에 시각화
- **Video Generation**: 사진으로 시네마틱 영상 자동 생성
- **On This Day**: 캘린더로 과거 여행 추억 탐색
- **100% Privacy**: 모든 처리는 기기 내에서 수행

### Supported Languages

- English
- 한국어 (Korean)
- 日本語 (Japanese)

### Platform

- iOS 26.0+ (iPhone & iPad)
- Mac (Designed for iPad)
